# AI-Era Cyber Defense Research

Research into how cyber defense should change when AI reduces the cost of reconnaissance, information integration, code analysis, vulnerability research, orchestration, execution, and adaptation.

## Research question

**What is defense in the AI era?**

The project treats attackers and defenders as feedback-driven exploration systems rather than reducing AI-era security to a single detection product or model.

### Attacker loop

Observation → Correlation → Hypothesis → Exploration → Execution → Feedback → Adaptation

### Defender loop

External Evidence + Internal Ground Truth → State Estimation → Hypothesis → Validation → Decision → Action → Feedback

## Current research themes

- AI-driven acceleration of reconnaissance, correlation, code analysis, and vulnerability research
- Agent orchestration, persistent state, and adaptive attack loops
- Defender structural advantages: internal ground truth, control-plane authority, telemetry, software provenance, deception, and recovery
- Evidence-driven exploration: Evidence → Claim → Hypothesis → Validation → Revision
- Public-information correlation and the provisional concept of a **Knowledge Attack Surface**
- Safe boundaries for autonomous defensive actions

## Research state

This repository is in an early research phase. Terminology, models, algorithms, and architecture may change as evidence and prior research are reviewed.

Observed facts, authoritative sources, third-party research, community signals, model inference, hypotheses, and unknowns should remain distinguishable. Inference is used to prioritize verification, not to silently convert uncertainty into fact.

## Safety scope

This is a defense-oriented research project.

The public repository is intended for defensive architecture, research methods, public case studies at an appropriate level of abstraction, remediation patterns, and reusable defensive algorithms.

Do not publish live credentials, personal data, non-public vulnerable endpoints, undisclosed vulnerabilities with actionable reproduction detail, step-by-step intrusion procedures, or current defensive bypass recipes.
